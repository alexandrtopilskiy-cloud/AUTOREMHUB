# AUTOREMHUB 0.36.1 — рекомендации и сохранение заявки

## Работы и запчасти

1. Вносите изменения в таблицы блока 04. «+» добавляет следующую строку.
2. Выбирайте существующую позицию через поиск. Если ЗЧ нет, откройте создание записи
   справочника из выпадающего списка, заполните обязательные поля и сохраните.
   Новая ЗЧ подставляется в исходную строку; прокрутка возвращается на прежнее место.
3. Количество, поставщик и цена реализации ЗЧ редактируются в строке заявки.
   Цена реализации справочника при этом не меняется.
4. Все изменения заявки, работ и ЗЧ фиксируются общей кнопкой с дискетой
   «Сохранить» либо «Сохранить и выйти». Отдельного сохранения строки ЗЧ нет.
   При ошибке хотя бы одной позиции сохранение целиком отменяется, введённые поля остаются в форме.

В списке производителей пустое поле показывает все согласованные действующие записи;
список можно прокрутить до конца. Ввод фильтрует совпадения.

## Перенести отложенные позиции в рекомендации

Сначала сохраните заявку. Отметьте чекбоксами нужные работы и/или ЗЧ и нажмите
«Добавить в рекомендации» под таблицами блока 04. Операция сразу создаёт документ
REC с собственным порядковым номером и убирает позиции из сметы заявки.

Доступно Заказчику при финальном согласовании, УК при маршрутизации и СТО при согласовании.
Заказанные ЗЧ и позиции с движениями сначала обрабатываются по существующей логике возврата:
перенести их таким способом нельзя.

В рекомендации фиксируются VIN, дата, снимки всех параметров позиций, пользователь
и индекс роли: У — УК, С — СТО, З — Заказчик. Прежние решения и суммы в истории
согласований исходной заявки сохраняются. «Параметры» открывает полный сохранённый набор полей позиции.

## Вернуть рекомендации в работу

Откройте «Рекомендации ТС» из блока 04 заявки, выберите документ REC и отметьте позиции.
Затем выберите доступную для редактирования заявку того же VIN и нажмите
«Переместить в заявку на ремонт», либо «Создать заявку из выбранного».

- Перенесённая позиция получает отметку и не может переноситься второй раз.
- Сохраняются исходные норма, ставка, наименование, количество, цена, сумма и причина ручной нормы.
- Запчасти проходят новое согласование; заказ/поставка автоматически не запускаются.
- Добавление в финальную заявку Заказчика возвращает её на согласование УК.
- Новый черновик закреплён за выбранным автомобилем. Заказчик заполняет текущий пробег,
  причину, контакт и время по обычным правилам. При создании УК/СТО пробег берётся
  из зафиксированных данных исходной заявки/истории; автомобиль и пробег остаются недоступны для изменения.
- Блокировка и ревизии не допускают повторного переноса другим пользователем.

## Согласование работ / ЗЧ в УК

В нижнем правом углу находятся две иконки:
- стрелка вправо — согласовать и передать Заказчику для финального подтверждения;
- стрелка влево — вернуть в СТО для корректировки. Обязательно укажите комментарий.

Согласование не зависит от того, корректировала ли УК смету: дальнейшее направление
выбирается кнопкой. При наведении на все командные иконки видны их подписи.

## Ручное добавление ТС (марки, модели)

В УК откройте соответствующий справочник и кнопку «Добавить ТС» рядом с импортом.
Заполните шаги: марка → модель → поколение/годы/кузов → тип двигателя → индекс двигателя
→ мощность → объём → трансмиссия → привод. Сохраняются прежние ограничения полей.

При полном совпадении набора параметров с имеющейся записью, включая архивную,
API сообщает о дубле. Изменение хотя бы одного параметра модификации создаёт иной вариант.

## Интерфейс

Действие по заявке выделяется красным, просмотр — серым, полностью закрытая заявка — зелёным.
Полные названия видны при наведении. Вкладки имеют отдельное место под полосу прокрутки,
а кнопка закрытия выровнена по центру. Информация о финальном согласовании занимает
пространство между командами сохранения/чата и командами маршрута.
