# Архив документации

Здесь хранятся документы, которые **не являются актуальными инструкциями**,
но имеют историческую ценность:

- **Отчёты о выполненных работах** (testing-report.md, WORK_CATALOG_BUILD_REPORT_*.md) —
  показывают состояние на конкретную дату.
- **Планы рефакторинга** (refactoring-*.md, infrastructure-plan.md) —
  описывают, что **планировалось**, а не что есть сейчас.
- **Baseline инфраструктуры** (infra-baseline.md) — снимок на дату.

**Не используйте эти документы как источник инструкций.** Актуальные
инструкции — в корне `docs/` и в `docs/DEPLOYMENT_AND_RECOVERY.md`.

Даты создания указаны в самих файлах. Если документ перестал быть
актуальным, но всё ещё может пригодиться — он здесь. Если устарел
полностью и вводит в заблуждение — удаляйте без сожалений.
